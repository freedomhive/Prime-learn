Privacy notice.

This website displays public property listing information managed by True Value Realty through Supabase. Visitors do not need to create accounts to browse published listings.

If you submit the website enquiry form, your name, phone, optional email, property interest, preferred area and message are sent to True Value Realty and stored in its private CRM so the team can respond. Enquiries are protected by server-side validation and request rate limits. Phone and WhatsApp links open the respective calling or messaging application; information you choose to send through WhatsApp is handled by WhatsApp.

Admin users authenticate through Supabase Authentication. Public website files contain only the Supabase project URL and public anon key. Secret keys, service role keys, passwords, and private database credentials must never be placed in browser files.
